# DATASCI 350 - Quiz 04 (make-up)

## Web APIs and JSON

This make-up quiz is worth 6% of the final grade, and covers lectures 18 and 19. It is open-book and open-notes. It is an individual assessment: please do not discuss the questions with anyone while you work. You have 75 minutes.

You may use AI tools on the same terms as the rest of the course: they are allowed, and you must be able to explain every command and every line you submit. The instructor may ask you to walk through part of your work after the quiz. An answer you cannot explain earns no marks.

### Rules

- Fork and clone this repository, and work in your clone on your laptop.
- Write every answer in `quiz04.ipynb`, in the empty cell below each task.
- Run all the cells from the top before you submit.
- Tasks 4, 6, 7, 8, 9, 10 and 11 and the bonus task send real requests to live APIs.
- Tasks 7 and 10 use `curl` in the terminal, as in lecture 18. On Windows, use WSL or Git Bash.
- Task 8 runs `scripts/pull_data.py` from the terminal.
- **Screenshots are not accepted.** Answers go in as code that runs, or as text you typed.
- Files created or uploaded on the GitHub website lose points.

### Files

The `data/` folder holds the files the tasks use.

- `library.json`: one reply from a fictional campus library API
- `wb_urban_ury_pry_page1.json`: share of the population living in urban areas in Uruguay and Paraguay, 2012 to 2024, as the World Bank sent it

The `scripts/` folder holds `pull_data.py`, which Task 8 uses.
